# Best IPTV Provider for UK 2026

Advanced SEO comparison website built with Vite, React and TypeScript.

## Live site

https://best-iptv-provider-uk.github.io/best-iptv-provider-uk-2026/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

GitHub Pages via the GitHub Actions workflow in `.github/workflows/deploy.yml`.

## Notes

Provider figures are advertised claims checked on 29 October 2026 and may change. This site is an independent comparison publication and is not affiliated with the listed providers.
